# 道路以目 · 沉默相变模拟器

依据《道路以目——沉默相变模型》PDF 的方程实现的网页模拟器。纯前端、零依赖,双击 `index.html` 即可运行(也可 `python3 -m http.server` 后访问)。

## 两种玩法

**沙盒模式(默认)**:10 个预设场景,左侧政策/结构旋钮实时可调。建议顺序:
①操场 20/21 人 → ③沉默不发出预警 → ⑥血腥星期日 → ⑨四十日纪念 → ⑩迟滞回线。
图表:时间序列 / 反应函数 F(x)(不动点与临界种子)/ 分岔图 / 有效承受上限分布(μ 系数)。

**对局模式(🎮)**:选边对抗 AI,瘟疫公司式胜负。
- 🏛 朝廷:60 轮内不让参与(x≥0.6)或兵变(d≥0.7)持续 3 轮 → 胜
- 📣 行动方:60 轮内点火成功 → 胜
- 每轮 1 行动点(上限 4),卡牌有冷却;AI 会针对你的行动升压/串联。
