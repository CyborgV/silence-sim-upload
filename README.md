# 道路以目

一个关于沉默、恐惧与集体行动的策略游戏。依据《道路以目——沉默相变模型》的方程实现。

纯前端、零依赖:双击 `index.html` 即可运行(或 `python3 -m http.server` 后访问)。

## 玩法

你有时站在街头,有时坐在宫殿里。**你看不到任何人的"门槛"**——只看得到街上有多少人、下面报上来的情报,和真假难辨的传闻。

- **民间一方**打出"对策"牌:集会、串联、罢工、地下刊物、曝光真相、悼念、劝说士兵……目标是越过临界点,或让执行者倒戈。
- **当局一方**调整常设"政策"(执法力度 / 警力 / 抓捕对象 / 舆论 / 关押)并打出行动牌。越强硬越贵;一旦越过人们认可的界线,每次处罚都会变成看不见的积怨。
- **战争迷雾**:执法越凶,下面的人越不敢说真话,情报越"报喜不报忧";封锁压住的不是记忆,只是记忆的公开。
- 每关结束后的**复盘**揭晓真实曲线:街头人数、执行者抗命、真实积怨 vs 你看到的积怨、真实临界点 vs 你的估计。

## 关卡

| 章 | 关卡 | 阵营 | 核心机制(对应论文) |
|---|---|---|---|
| 序章 | 操场上的二十一个人(教程) | 民间 | 临界种子:20 人熄灭,21 人燎原(p15–16) |
| 一 | 厉王弭谤 · 约前844 | 当局 | 沉默不发出预警、镇压债务(性质一、二) |
| 二 | 面包与士兵 · 彼得格勒 1917 | 民间 | 群众与执行者两层反馈(性质四) |
| 三 | 四十日 · 伊朗 1978 | 民间 | 延迟记忆核:四十日悼念周期 |
| 四 | 戒严之夜 · 波兰 1981 | 当局 | 按名单拘押、断联、财政代价(性质九) |
| 五 | 春夏之交 · 北京 1989 | 民间 | 执行者门槛;外地部队切断人群影响 |
| 六 | 我们是人民 · 莱比锡 1989 | 民间 | 信息与教会网络(性质五) |
| 七 | 一张白纸 · 2022 | 民间 | 审查、偏好伪装、悲剧后的集体确认 |
| 八 | 看不见的裂缝 · 朝鲜 | 民间 | 识别的限制:让临界点"出现" |

另有**自由对局**(虚构城市,任选阵营与社会类型)和**模型实验室**(`lab.html`,原沙盒:全部参数、反应函数、分岔图)。

史实部分力求准确;数值是为玩法设定的示意,不是历史估计。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` `game.css` `app.js` | 游戏界面:标题、关卡、简报、对局、事件、新手引导、复盘 |
| `city.js` | 城市视图(每个点是一群人) |
| `engine.js` | 游戏引擎:政策/对策、对手 AI、情报迷雾、事件、星级 |
| `levels.js` | 关卡数据:史实简报、事件时间线、结局与模型结论 |
| `model.js` | 模型核心(论文 p1–8 方程 + 可选的游戏层扩展) |
| `lab.html` `lab.js` | 模型实验室(原沙盒界面) |
| `tests.js` | 论文数值自检 `node tests.js` |
| `tune.js` | 沙盒场景叙事检查 `node tune.js` |
| `playtest.js` | 关卡平衡测试 `node playtest.js [关卡id|all] [局数]` |

## 校验

- `node tests.js`:37/37(论文 p5/p16 算例、Catalan 级数、迟滞阈值、执行者几何侵蚀等)
- `node tune.js`:21/21(实验室各场景的预期玩法)
- `node playtest.js all`:只看玩家读数的机器人跑各关——认真玩在大多数关卡能赢,什么都不做会输,一味铁腕常常适得其反
