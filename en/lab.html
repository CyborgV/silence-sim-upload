🏛 Repression apparatus policy
P and P̄ together set how far things go “over the line”, (P−P̄)₊: it drives both memory accumulation and enforcer disobedience. P̄ is the line society accepts, not a technical parameter.
🪖 Enforcers policy
Refusal rule: α·x + β·d + δ(P−P̄)₊ ≥ ψ. Each layer can be stable on its own and still become unstable when coupled (Property 4).
📺 Information environment policy
x̂=(1−ω)·acquaintances' participation+ω·(compressed global share). The smaller ω, the more people rely on those around them (church circles). More accurate information does not necessarily raise participation — it depends on which way it was biased before (Property 5).
🧠 Memory & mood structure
b←(1−ρ)b+γw(P−P̄)₊ζ. The same public record can hide very different amounts of accumulated memory — repression debt (Property 2).
